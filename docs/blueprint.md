# **App Name**: ScentSense

## Core Features:

- QR Code Scanner: Scan a QR code to access the fragrance app directly.
- Fragrance Recommendation Tool: Receive AI-driven fragrance recommendations based on the user's family scent preferences. The tool will use reasoning to identify optimal matches from Zara Argentina's catalog, adapting recommendations over time based on user input and fragrance data.
- Zara Fragrance Filter: Filter fragrances specifically from the Zara Argentina brand.
- Scent Family Grouping: Group fragrances based on their respective scent families.
- Fragrance Detail Display: Display detailed notes of each fragrance when a fragrance name is clicked.

## Style Guidelines:

- Primary color: Light, muted rose (#F0B2B6) evoking a sense of subtle elegance and the floral aspect of many fragrances.
- Background color: Very light, desaturated rose (#F9EBEA) to create a soft, inviting backdrop.
- Accent color: Soft lavender (#D2B4DE) as an analogous hue, providing contrast and highlighting interactive elements.
- Body and headline font: 'Alegreya', a humanist serif with an elegant and intellectual feel, appropriate for longer passages of text.
- Simple, line-based icons to represent different fragrance families and notes.
- Clean and spacious layout, emphasizing imagery and ease of navigation.
- Subtle transitions and animations to enhance user engagement without being distracting.
